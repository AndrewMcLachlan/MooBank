# Implementation plans

Feature designs and implementation plans, written before the work starts.

- Active plans live in this folder, named `YYYY-MM-DD-<feature>-design.md` or `YYYY-MM-DD-<feature>-plan.md`.
- Once the work has shipped, move the plan to `archive/`. Archived plans are history: they describe the codebase as it was, so check the code before relying on one.
- Review reports go in `.agents/reviews/`.
